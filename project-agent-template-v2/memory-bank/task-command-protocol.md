# 任务口令协议

## 支持的口令

### 中文口令（推荐）

| 口令 | 含义 |
|------|------|
| `执行 P1-W1-T2` | 执行单个任务 |
| `执行 P1-W1-T2, P1-W1-T3` | 按顺序执行多个任务 |
| `检查 P1-W5-T1` | 仅检查不修改 |
| `继续` | 执行下一个未完成任务 |

### 完整格式

- 单任务：`执行任务：P1-W1-T2`
- 多任务：`执行任务清单：P1-W1-T2, P1-W1-T3`
- 仅检查：`仅检查任务：P1-W5-T1`
- 继续推进：`继续下一个任务`

## AI 固定执行流程

1. 从对应 phase 的 task index 定位任务
2. 检查依赖是否已完成
3. 在对应 playbook 中将任务状态标记为「进行中」
4. 执行最小范围改动
5. 按验收项自测
6. 在 playbook 中更新状态与执行记录
7. 返回统一报告

## 状态模型说明

- `phase1-playbook.md`、`phase2-playbook.md` 维护任务状态
- `phase1-task-index.md`、`phase2-task-index.md` 只做任务定位
- `scripts/ralph/prd.json` 与 `scripts/ralph/progress.txt` 仅服务 Ralph，不等于 phase 状态板

## 统一报告格式

```text
[任务] P1-W1-T2
[状态] 已完成/阻塞
[改动文件] ...
[验收结果] ...
[阻塞项] ...
[建议下一步] 执行 P1-W1-T3
```
