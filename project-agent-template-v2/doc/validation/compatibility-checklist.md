# Compatibility Checklist（Optional）

> 本文件是 **可选** 的兼容性约束模板。
>
> 适用：存在明确平台、版本、运行时、框架或环境边界的项目。

## 目标

在项目接入新平台/版本/运行环境时，明确哪些能力已经验证兼容、哪些还没有。

## 工程级检查

- [ ] 工程目录结构符合目标环境要求
- [ ] 依赖/工具链版本已固定
- [ ] 不使用目标环境不支持的 API / 语法 / 目录约定
- [ ] 关键入口能正常加载

## 代码级检查

- [ ] 核心逻辑与平台 API 的耦合边界清晰
- [ ] 兼容层只做 adapter，不下沉 domain 规则
- [ ] 新增写法未越过目标版本能力边界
- [ ] 自动检查覆盖到兼容层需要的最小文件范围

## 运行级检查

- [ ] 最小主流程可运行
- [ ] 关键日志 / Console 无阻塞错误
- [ ] 降级路径可观察
- [ ] remaining risks 已明确记录

## 注意

- compatibility checklist 关注的是“当前环境边界”，不是完整产品验收
- 若需要人工打开特定版本工具/平台，必须在 manual acceptance checklist 中同时留下真实人工步骤
- 若项目不存在明确平台/版本约束，可不启用本文件
