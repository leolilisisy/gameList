# 发布前检查清单

## 目标

用于在阶段性发布、内测、Demo 或交付前确认项目是否满足最小上线 / 演示 / 验收要求。

## 一、构建与质量门禁

- [ ] 构建命令通过：`{{BUILD_COMMAND}}`
- [ ] 静态检查通过：`{{LINT_COMMAND}}`
- [ ] 测试命令通过，或已记录无测试项原因：`{{TEST_COMMAND}}`

## 二、核心主流程

- [ ] 主流程可运行
- [ ] 主流程失败时满足：`{{SAFE_FALLBACK_RULE}}`
- [ ] 核心功能达到 Phase 当前验收要求
- [ ] 关键边界条件已验证

## 三、可观测性

- [ ] 核心事件符合 `{{EVENT_SCHEMA_PATH}}`
- [ ] 关键性能指标 `{{PERF_METRICS}}` 可采集
- [ ] 关键失败路径可定位

## 四、文档与状态

- [ ] Phase 状态已更新到 playbook
- [ ] 架构文档已同步
- [ ] 验证结论已记录
- [ ] 风险项与阻塞项已明确

## 五、Ralph（如适用）

- [ ] Ralph 运行手册与实际行为一致
- [ ] `--check` / `--status` / `--recover` 可用
- [ ] `COMPLETE` / `BLOCKED` / `MANUAL_INTERVENTION_REQUIRED` 语义已明确
- [ ] 没有遗留的 stale run-state / stale lock

## 六、最终结论

- [ ] 可以发布 / 演示 / 内测
- [ ] 仍有阻塞项，暂不发布
