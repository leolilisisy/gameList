# Manual Acceptance Checklist（Optional）

> 本文件是 **可选** 的人工验收模板。
>
> 适用：需要人工打开应用、人工观察 UI/Console/设备行为、人工做体验判断的项目。

## 目标

记录那些不能被自动化命令替代的验证步骤，避免把人工验收伪装成自动验证。

## 使用原则

- `manual:` 表示必须由人工执行并记录结果的真实步骤
- 没有人工记录，就不要写“已通过”
- 若当前轮只能完成自动部分，必须诚实写出剩余人工步骤

## 通用人工验收模板

- [ ] 打开目标环境 / 应用 / 场景 / 页面
- [ ] 执行最小主流程
- [ ] 检查关键可观察结果
- [ ] 检查 Console / 日志 / 设备侧是否出现阻塞错误
- [ ] 记录版本、环境、结果与 remaining risks

## 注意

- 人工验收记录属于证据，不是待办口号
- 若需要多次执行，建议每次都追加新记录，而不是覆盖旧结果
- 若某项仍未观察到，应写“未观察到 / deferred”，不要写成已完成
