# 指标记录模板

## 目标

用于统一记录关键性能、质量、稳定性指标，便于阶段性复盘与比较。

## 核心指标

| 指标 | 说明 | 口径 | 当前值 | 目标值 |
|---|---|---|---|---|
| `{{PERF_METRICS}}` | 主流程性能指标 | 按项目定义 | 待填写 | 待填写 |
| `success_rate` | 主流程成功率 | 成功次数 / 总次数 | 待填写 | 待填写 |
| `fallback_rate` | 回退比例 | fallback 次数 / 总次数 | 待填写 | 待填写 |
| `blocking_issue_count` | 阻塞级问题数量 | 当前未关闭数量 | 待填写 | 待填写 |

## 采集说明

- 指标定义必须与 `event_schema.md` 和项目当前阶段目标一致。
- 若项目存在多环境或多设备分层，应明确写出口径。
- 若指标无法自动采集，需说明人工采集方法。
